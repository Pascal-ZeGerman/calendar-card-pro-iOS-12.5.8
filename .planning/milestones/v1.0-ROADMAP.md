# Milestone v1.0: iOS 12.5.8 Compatibility

**Status:** SHIPPED 2026-03-29
**Phases:** 1 (originally planned as 4, pivoted to vanilla JS rewrite)
**Total Plans:** 3 (Phase 1 build pipeline) + 1 (vanilla JS rewrite)

## Overview

Targeted compatibility backport of Calendar Card Pro to run on iOS 12.5.8 Safari (WebKit 606.x). Originally planned as a 4-phase incremental fix (build pipeline, component rendering, touch interactions, CSS polish). After Phase 1 build fixes proved insufficient (Lit internals still failed at runtime on Safari 12), the approach pivoted to a full vanilla JS rewrite — a single 844-line file with zero dependencies that replaced the 266KB Lit bundle.

## Phases

### Phase 1: Build Pipeline (Original)

**Goal**: Produce a Safari 12-parseable bundle with correct esbuild target, pinned Lit version, and syntax fixes
**Depends on**: Nothing
**Plans**: 3 plans

Plans:
- [x] 01-01: Source + build config changes (emoji regex fix, esbuild safari12, tsconfig ES2019)
- [x] 01-02: Dependency pin + verify script (Lit 2.8.0 overrides, verify-bundle.sh)
- [x] 01-03: Execute build, verify output, push to GitHub, checkpoint iOS 12 device test

**Outcome**: Bundle parsed without SyntaxError but Lit runtime still failed on Safari 12. Led to pivot decision.

### Pivot: Vanilla JS Rewrite

**Goal**: Replace entire Lit-based card with a hand-written vanilla JS custom element using only Safari 12-native APIs
**Depends on**: Phase 1 findings (Lit runtime incompatible with WebKit 606)

Deliverables:
- [x] Single-file vanilla JS custom element (844 lines, 24KB)
- [x] ES2015 class syntax, Custom Elements v1, Shadow DOM v1
- [x] Zero dependencies — no Lit, no dayjs, no framework
- [x] Touch + click event handling (no Pointer Events)
- [x] Safari 12-safe CSS (no color-mix, no gap, no :focus-visible)
- [x] PR review fixes: multi-day events, error logging, input validation

## Milestone Summary

**Key Decisions:**
- Vanilla JS rewrite instead of incremental Lit fixes — Lit internals hit WebKit 606 quirks beyond syntax
- ES2015 class syntax mandatory — Custom Elements v1 requires true class extending HTMLElement
- Stale .gz file discovery — HA serves pre-compressed files preferentially; must remove old .gz on deploy

**Issues Resolved:**
- iOS 12 SyntaxError on card load (original bundle)
- Lit runtime failures on Safari 12
- Multi-day timed events only appearing on start day
- Silent API error swallowing

**Issues Deferred:**
- Today indicator (dot/pulse/glow) — excluded from lite rebuild
- Day/week separators — excluded from lite rebuild
- Tap-on-event details — excluded from lite rebuild
- Card editor UI — YAML-only configuration
- Weather integration — excluded from lite rebuild

**Technical Debt Incurred:**
- CSS built as string concatenation (could use array-join for readability)
- Duplicated DOM construction for time/location rows (could extract helper)
